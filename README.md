# Game World Lab

Public static preview of an original isometric game universe by **AndriiEagle**.

This is a standalone, early experimental prototype with a clickable and keyboard-controlled isometric map. It is **not** a released game or a copy of private project source code.

## GitHub Pages

This project is ready to publish from `main` → `/(root)` using **Settings → Pages → Build and deployment → Deploy from a branch**.

Once enabled, the expected address is https://andriieagle.github.io/game-world-demo/.

## Local preview

Open `index.html` in a modern browser. No dependencies, install steps, paid APIs, external calls or backend.

- `index.html` — page markup
- `style.css` — responsive visual design
- `script.js` — deterministic canvas terrain interaction
- `.nojekyll` — disables Jekyll preprocessing

GitHub Pages serves static files only; do not store credentials or server secrets here.
